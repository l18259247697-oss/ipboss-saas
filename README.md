# 一键追爆 · 全自动 IP 智能体（SaaS）

把一条爆款短视频链接，自动变成「**换成你行业的文案 + 你的声音 + 你的脸对口型**」的新视频。
面向实体老板做短视频获客的一站式工具，可作为 SaaS 自营售卖（注册登录、按点数消费）。

## ✨ 功能（6 步全自动流水线）

1. **文案来源** — 输入原文，或抖音链接下载及转写（原链接已实测，其他作品仍可能受平台访问限制）
2. **改写文案** — 大模型把文案改写成你所在行业的版本（OpenAI 兼容，DeepSeek/豆包/通义…）
3. **音频生成** — 免费 TTS（edge-tts）或 **克隆你自己的声音**（当前选定千问 3.0 Plus，保留旧 CosyVoice 适配器）
4. **口播底版** — 上传本人的清晰正脸视频；当前 VideoRetalk 路线不接受照片代替
5. **改口型成片** — 使用原人物视频和新配音生成 VideoRetalk 口型；异步任务保存供应商任务号
6. **最终成片** — 校验有效音视频后在线预览、下载；媒体校验不等于自然度验收

附带：用户注册登录、点数计费、管理后台（配 key、管账号点数、改品牌）。

输入草稿按账号保存在当前浏览器，可在刷新、重登、关页重开后恢复；清除站点数据或换设备不保证恢复未提交草稿。已提交任务及已上传完成的素材保存在服务端，历史任务可重新选择。尚未上传完成的文件不支持断点续传。

## 🧱 技术栈

- 后端：FastAPI + SQLite，音视频检查另需 FFmpeg/ffprobe
- 前端：原生 HTML/CSS/JS，单页应用，深色橙色风
- AI 能力（均可插拔）：
  - 转写 `openai-whisper` 或百炼 `qwen-audio-3.0-asr-flash` ｜ 改写 OpenAI 兼容大模型 ｜ 配音 `edge-tts`
  - 当前实测口型：阿里云百炼北京 `videoretalk`
  - 当前选定声音：百炼北京 `qwen-audio-3.0-tts-plus`
  - 历史本地/自建适配器保留，但不代表已部署或已完成商用、质量验收

## ⚙️ 配置

配置读取顺序：默认值、`backend/.env`、`backend/.env.local`、进程环境，最后由 `data/config.json` 覆盖。已有后台配置优先于环境文件；仅填 Key 不会把已保存的 `server` 自动切成云 API。

当前选定的服务配置（2026-09-29 接入千问 3.0，实际验收以 E2E 记录为准）：
- `LLM_BASE_URL / LLM_API_KEY / LLM_MODEL`：改写文案用的大模型
- `LS_PROVIDER=dashscope`、`DASHSCOPE_API_KEY`：百炼北京 VideoRetalk
- `ASR_PROVIDER=dashscope`、`ASR_MODEL=qwen-audio-3.0-asr-flash`：链接原视频的云端转写，复用北京 Key；默认 `local`，不因填写 Key 自动外发。2026-10-14 原固定快照在当前账号返回 404，已显式切换到 3.0 的原生同步接口并实测转写成功；旧 Qwen3 快照适配器保留，但不自动回退或重试。云端识别直接使用音频，不以标题或大模型润色冒充原话。同步接口限制为 5 分钟以内且 Base64 不超过 10 MB；当前 24kHz WAV 可能先达到文件大小限制。结果及请求号保存在任务的 `prep/source-asr.json`，未知提交不会自动重试或切换服务。
- `VC_PROVIDER=dashscope`、`VC_MODEL=qwen-audio-3.0-tts-plus`：本人音色克隆，复用 `DASHSCOPE_API_KEY`
- 已有 `data/config.json` 时，对应设置 `lipsync.provider=dashscope`、`voice_clone.provider=dashscope`、`voice_clone.model=qwen-audio-3.0-tts-plus`。旧 `VC_API_KEY` 仍仅供硅基流动使用，不会发给百炼。
- 千问音色缓存与配音请求记录在 `data/voice-clone/`，按模型、账号、录音区分；未知提交不自动重试，下载中断复用原结果。当前仅支持单个 Uvicorn worker；重启后任务进入待恢复状态，由页面继续查询，不自动重跑付费步骤。
- 完整配音超过 VideoRetalk 单次 120 秒限制时，按邻近低能量位置拆成小于 120 秒的请求，使用同一连续人物时间线，各带约 0.25 秒原始上下文；串行生成并保留每段任务号，裁去上下文后拼接画面并配回原始完整音轨。不会重复段落、删稿、加速或将音频裁到 120 秒；已完成分段恢复时不重新生成。旧的未完成分段计划不会自动迁移或重做。分段边界和短底版延长的自然度仍需人工检查。
- 高于 40fps 的底版在 `video_extension=false` 分段请求中按 59.5 秒核心上限处理，为上下文和供应商 60 秒边界留余量；供应商返回少量高帧率取整偏差时最多吸收 3 帧，大幅偏差仍保留结果并停止，不自动重做付费任务。
- 改写以用户提供的业务事实为依据，不再要求凑原片时长；对已知速度/效果承诺增加局部拦截。这不是通用事实核验器，发布前仍需审稿。
- `credits_per_video / register_bonus`：计费

Key 只填本机配置文件，不发到聊天里。`.env.local` 和整个 `data/`、`outputs/` 已忽略。未部署自建服务时不要配置 `127.0.0.1:8001` 冒充可用服务。

任务提交会使用 Idempotency-Key 绑定当前账号和输入快照：相同请求在网络结果不明后再次提交会回读原任务，不重复扣点；同一键换输入会被拒绝。扣点数与创建任务在同一个 SQLite 事务内完成。它只解决本地任务账务一致性，尚未替代正式支付订单和供应商费用对账。

点数变化现在会写入 SQLite `credit_ledger`：注册赠送、管理员调整、任务扣点和失败退款都有方向、变更后余额、任务号和请求号；管理员可通过 `/api/admin/credits/ledger` 只读核对。历史余额没有自动倒推流水，正式支付仍需接订单和支付回调。

2026-10-24 已将用户人脸、声音样本、任务音频和成片改为登录后按账号读取的受保护媒体接口，并通过 HttpOnly 会话 Cookie 支持浏览器播放；旧的 `/outputs`、`/data/faces`、`/data/voices` 静态公开目录不再挂载。登出会撤销浏览器会话 Cookie。该实现已用隔离账号回归验证，但仍不是对象存储签名 URL、CDN、限流、备份或正式支付系统。

同日增加了 `/health` 与 `/ready` 探针、上传大小限制和任务文本长度限制。探针只报告运行状态和非敏感配置检查，不会调用付费供应商；这仍不能替代生产监控、队列、对象存储和告警。

任务执行增加了进程内并发槽，默认一次只跑一个生成任务，避免同一进程同时抢占显存；它仍不是跨进程持久化队列。
